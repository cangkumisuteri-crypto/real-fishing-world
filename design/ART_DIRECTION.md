# REAL FISHING WORLD — ART DIRECTION（AI-2 / 世界の見た目 + モバイルUI）

対象: iPhone 縦横対応 / Three.js / 優先順位は **動作 > 操作性 > リアルさ > fps > 見た目**（SPEC 第10章）。
方針: 「リアル寄りの低ポリ（stylized realism）」。形はシンプル、質感と光で港らしさを出す。`src/` には触れない（この文書は参照用）。

### 作り方の予算（iPhone 想定）
- 描画コール < 150、全体 < 15 万三角形、実体オブジェクトは InstancedMesh（ビット/テトラ/ブイ）。
- テクスチャ: 本ディレクトリの 4 枚（512²）を使い回し。UV 繰り返し目安: concrete 1 枚=2 m、rock 1 枚=1.5 m、sand 1 枚=3 m、wood 1 枚=1 m。`RepeatWrapping` / `colorSpace = SRGBColorSpace` / `anisotropy = 4`。
- 地面の単調さは **頂点カラーの乗算 + 低周波ノイズの2枚目UV** で崩す（テクスチャ追加不要）。
- 影: 動的影は key light の 1 枚のみ(1024², 範囲はプレイヤー周辺 40 m)、その他は焼き込み風の頂点 AO。

## 3. 水の見た目

### 方針
モバイル負荷優先。**カスタム ShaderMaterial の 1 枚板**（高さ方向は sin 波、法線は解析的、反射は本物の環境マップなし=空グラデを直接サンプル）。SSR/Reflector は使わない。

### 設定値
```
Mesh        : PlaneGeometry(400, 400, 96, 96)   // 近距離ほど密にしたい場合は 2 枚(近 128m/遠 400m)
Waves(頂点) : 3 本の sin 合成（方向 θ, 波長 λ, 振幅 A, 速度 v）
              1) θ=20°  λ=18 m  A=0.18  v=1.1
              2) θ=-35° λ=7 m   A=0.07  v=1.6
              3) θ=75°  λ=2.5 m A=0.02  v=2.3     // 港内は A を 0.4 倍
              港内/岸壁前は波高 ×0.3、外洋/防波堤外は ×1.0（頂点カラーのマスクで）
色          : 深さ(水深マップ or 岸からの距離)で shallow⇄deep を mix。上表の水色を使用
Fresnel     : F = F0 + (1-F0) * pow(1 - max(dot(N, V), 0), 4.0), F0 = 0.02
              color = mix(waterColor, skyColor(reflect(-V,N)), F * 0.9)
              （見下ろしでは水中の色、遠方/低角では空の色）
スペキュラ  : Blinn-Phong 風 pow(NdotH, 180) * keyLightColor * 0.8（夜は月で 0.3）
透明度      : opacity 0.92（岸際は 0.65）。transparent: true, depthWrite: false 推奨
              浅瀬/足元の海底はテクスチャを透かす（岸壁際 0〜1.5 m を浅色にフェード）
フォーム    : 岸壁・防波堤・テトラ際に幅 0.6〜1.0 m の帯。
              foam = smoothstep(0.55, 0.75, noise(uv*8 + t*0.15)) * shoreMask
              色は上表の foam、波頭は波高上位 8% に追加
法線        : 解析法線 + 小さな 2 枚の scroll 法線ノイズ（256² タイリング、速度 ±0.02/s）で細かな揺れ
フォグ      : ShaderMaterial に fog: true、`#include <fog_*>` を使い、遠景で空と一致させる
更新        : uTime のみ。CPU 側のジオメトリ更新はしない
```
- 釣り中のウキ周りは波紋リング(スプライト、半径 0→0.6 m、1.2 s で消える)を重ねる。
- 水面下の魚影: 暗い楕円(スプライト `#02101C` α0.35)をシャロー/岸壁際のみで表示可。
- 性能目安（iPhone 12 級）: 水だけで 1.0 ms 以下。実機未検証。`renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`、低速時は 1.5 → 1.0 に段階的に下げる。`antialias: false`（代わりに高 DPR）。

## 4. モバイル HUD 設計

### 4.1 共通ルール
- 単位: CSS px = iOS の pt。`<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`。
- **セーフエリア**: すべての固定 UI は `env(safe-area-inset-top|right|bottom|left)` を加算。
  `left: calc(env(safe-area-inset-left) + 16px)` のように書く。縦長は top ≈ 47–59 / bottom 34、横向きは left/right 47–59 / bottom 21。
- **タップ領域 ≥ 44×44 pt**（主要ボタンは 56–80）。隣接ボタンの間隔 ≥ 12 pt。見た目が小さくても `::before` で当たり判定を拡張。
- **重ならない**: 画面を「ゾーン」に分け、ゾーンごとに 1 種類の UI しか置かない（下記 4.2）。ボタンは各ゾーンの **グリッド座標** に固定配置（自由配置しない）。
- **スワイプ視点エリア**は「右半分(x ≥ 50%) の、ボタン類以外の全面」。ボタン上のタッチはスワイプにならない（`pointerdown` の target で判定）。
- ジョイスティックは左下 `x < 45%` かつ 縦持ち `y > 55%` / 横持ち `y > 45%` の領域で **浮動式**（最初にタッチした位置が中心）。可視の基準リング(初期位置)も常に表示。
- マルチタッチ: ジョイスティック(左 pointerId)とスワイプ(右 pointerId)は独立。ボタン押下中もスワイプ可。
- `touch-action: none; user-select: none; -webkit-touch-callout: none; overscroll-behavior: none`。ダブルタップ拡大/ピンチ無効。
- 文字: 本文 14–16 pt、ボタンラベル 12–13 pt（太字）。コントラスト比 4.5:1 以上、夜は縁取り付き。ボタン色: 通常 `rgba(12,22,38,.55)`+白文字、主アクション `#FF8A3D`、危険/やめる `#E5484D`。
- 実/デモ表示: 上部チップに「LIVE」または「デモ」を明示（SPEC: 実データとデモを区別）。
- モード切替: 釣り開始で **移動UI→釣りUIへクロスフェード 150 ms**。**同じ位置に別の意味のボタンを置かない**（誤タップ防止。主アクション位置だけは固定でラベルが変わる）。

### 4.4 釣りモード（Fishing mode）

## 5. 付録: テクスチャ（design/textures/）
`concrete.webp` `rock.webp` `sand.webp` `wood.webp`（各 512×512、シームレス、自作 CC0、各 < 25 KB）。生成スクリプト `gen_textures.py`、確認用 `_preview_2x2_all.png`（2×2 タイル、非ランタイム用）、`LICENSE.txt`。
- 用途: concrete=岸壁/防波堤/床、rock=岩場・基礎、sand=砂浜、wood=デッキ/桟橋/軒/店の板。
- すべて albedo のみ。法線/粗さは作らない（モバイル負荷）。必要なら `MeshLambertMaterial` か `MeshStandardMaterial(roughness 0.9, metalness 0)` に載せる。
- WebP は iOS 14+ の Safari で対応。
