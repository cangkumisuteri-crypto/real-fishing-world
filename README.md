# REAL FISHING WORLD — Phase 1（歩ける 3D 港プレビュー）

架空の港「波戸浦港」を一人称で歩き回り、好きな水際で「釣り開始」を押すと釣りの構えに入れる、スマホ（iPhone Safari 最優先）向けの 3D プレビューです。

- TypeScript + Three.js + Vite（静的ビルド、`base: './'`）
- 実装済み: 3D 港（防波堤・岸壁・砂浜・岩場・テトラ・建物・つり具店の仮置き）、波と空（現地時刻の昼夜）、バーチャルジョイスティック＋スワイプ視点（PC は WASD＋ドラッグ）、衝突判定、釣り場判定＋釣りモード UI、マップ、メニュー（画質・速度・視点）、localStorage セーブ
- 未実装（次の Phase 以降）: キャスト／アタリ／ファイト／魚／所持品・経済／天気・潮の実データ など。`SPEC_NOTES.md` に仕様メモあり。

## 使い方
```
npm install
npm run dev        # 開発
npm run build      # dist/ に静的ファイルを生成
node tests/qa.mjs  # Playwright QA（要 dist/、WebKit/Chromium）
```
URL パラメータ: `?t=21`（時刻をデモ指定）, `?q=low|mid|high`, `?qa=1`（QA フック）。

テクスチャは CC0（`src/assets/textures/LICENSE.txt`）。

## Phase 2（ウキ釣り）
キャスト（狙い→パワー／上フリック）→ 3D ウキ・ライン・オモリ → 前アタリ／エサ取り／エサ消耗 → 合わせ → ファイト（ドラグ・巻き・竿角度・テンション・走り・根潜り・疲労・ラインブレイク・バレ）→ 取り込み（図鑑・釣果ログ・セーブ v2）。
振動は `navigator.vibrate`（非対応の iOS は画面揺れ＋音）。実機 iPhone での操作感・fps は未検証。QA: `node tests/qa.mjs`（`?qa=1` で `__rfw.fishing` フックを使う決定的テスト）。

## Phase 2.1（操作性・AUTO・初回チュートリアル）
- **↩ 回収ボタン**: ウキが水中でヒット前なら常時表示。1タップで約1秒の巻き戻し（ウキが手前へ滑って回収→仕掛け維持）。長押し「巻く」の通常リールも従来どおり。根掛かり中は35%で仕掛けロスト。
- **魚モデル/釣果表示**: 9魚種（アジ/サバ/カサゴ/メバル/チヌ/シーバス/タチウオ/マダイ/ブリ）を自然な比率・色・サイズに作り直し。釣果表示は縮小して小さなゆらぎのみ。`node tests/fishpreview.mjs` で全魚種の確認画像（tests/out/fish_sheet.png）。
- **操作性**: 前回のキャスト強さ/仕掛け/エサを記憶し「狙う→投げる」を1タップ化（ヒット後も同位置へ再キャスト）、場面に必要なボタンだけ表示、大きいボタン+ラベル、アタリ/ヒットの大きな合図、短い一回限りヒント、片手モード（メニュー→右/左）、ファイトの「アシスト」（ドラグ自動調整・走りで巻きを止める。巻く長押しだけで取り込み可。OFFで従来のマニュアル）。キー: Space=メイン操作 / Q=回収 / T=AUTO。
- **AUTO（おまかせ）**: 🤖ボタン/設定でON。キャスト→合わせ→ファイト→取り込み→結果を自動で行い、図鑑/釣果ログは通常どおり記録。初回起動で「自分で釣る/おまかせで釣る」を選択（QA・既存セーブは選択なし）。
- **初回チュートリアル（最大4ステップ・1行・約30秒）**: 実操作で進む。スキップは常時表示、メニュー「遊び方をもう一度」で再開。以降は一回限りの文脈ヒントのみ。
- セーブ v2 に任意フィールドを追加（`auto/assist/oneHand/castPower/modeChosen/tutStep/seenHints`）。旧セーブ/壊れた値は既定値に丸める。
- QA: `tests/phase21.mjs`（回収・クイックキャスト・合図・アシスト・AUTO全サイクル・6画面サイズ×片手3種×7局面のレイアウト・旧セーブ・初回選択/チュートリアル）。アシスト/ボット比較は `node tests/sim/build.mjs tests/sim/assist_sim.ts /tmp/a.mjs && node /tmp/a.mjs`。
- 既知の仕様: 初期タックルでは大型（シーバス60cm/ブリ60cm等）はアシスト/ボットでも取り込み困難（タックル成長が前提）。小型（アジ/サバ/カサゴ/メバル）は取り込み可。
- 未検証: 実機 iPhone の操作感・fps・振動・音・WebKit セーフエリア・人間による難易度。
